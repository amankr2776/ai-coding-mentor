# **App Name**: CodeMentor AI

## Core Features:

- Personalized Problem Generation: Generate unique coding problems tailored to the user's identified weak areas, preferred languages, and past mistakes by leveraging Hindsight memory and a powerful LLM tool.
- Intelligent Code Execution & Feedback: Allow users to write and submit code in 14 programming languages, receive real-time execution results via Judge0, and get AI-powered detailed feedback including error analysis and suggestions for improvement.
- Contextual Hint & Debugging Mentor: Provide smart, level-based hints and step-by-step debugging assistance, drawing upon the user's specific problem, submitted code, and relevant past errors recalled from Hindsight memory.
- AI-Powered Chat Mentor: Interact with a conversational AI assistant that offers personalized study plans, concept explanations, and strategic advice, all grounded in the user's comprehensive learning history stored in Hindsight.
- Comprehensive Learning History & Pattern Analysis: Track and display a detailed log of every mistake made, problem attempted, and hint requested. Hindsight memory automatically identifies common mistake patterns and areas of struggle.
- Gamified Progress & Analytics Dashboard: Visualize learning progress with an interactive dashboard showcasing stats, achievements, XP, daily streaks, and AI-generated weekly summaries, encouraging consistent practice and skill development.

## Style Guidelines:

- The theme employs a sophisticated dark palette: a deep background of '#0f172a' creates a professional, focused environment. Interactive elements pop with a primary blue '#3b82f6', conveying clarity and reliability. Layered surfaces of '#1e293b' and '#334155' build visual depth, while a bright '#f1f5f9' ensures text readability. Strategic accents like a success green '#22c55e', an error red '#ef4444', and a warning orange '#f59e0b' provide immediate feedback, all within a muted border of '#475569'.
- The 'Inter' sans-serif font is used throughout the application for its modern, clean, and highly readable characteristics, suitable for both headlines and detailed code snippets. Note: currently only Google Fonts are supported.
- Utilize sleek, minimalist line icons for navigation and features, paired with engaging and expressive emojis for gamification elements like streaks, badges, and problem categories, enhancing the user experience.
- A mobile-responsive layout prioritizes clean content presentation with generous use of 'rounded-xl' for all prominent cards and containers, and 'rounded-lg' for interactive elements like buttons, contributing to a modern and approachable aesthetic.
- Subtle, fluid animations enhance interactivity: gentle 'fade-in' effects for page transitions and smooth 'slide-up' motions for new content cards, complemented by a delicate, responsive 'glow' on primary interactive elements upon hover or focus.
